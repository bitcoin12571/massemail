INCONSISTENCY PATTERNS (Code Quality)
───────────────────────────────────────────────────────────────────────────────────────────────────

Pattern 1: Mixed Logging Methods
  - Some routes use logger service
  - Other routes use console.log/error directly
  - Result: No unified log level control

Pattern 2: Missing Error Context
  - Many services throw errors without logging
  - Routes must catch and log again
  - Result: Potential gaps, duplicate logging

Pattern 3: Silent Failures
  - Catch blocks that swallow errors
  - Continue processing as if successful
  - Result: Data loss, audit gaps

Pattern 4: Exposed Technical Details
  - Multiple routes expose error.message
  - Different error types leak different info
  - Result: Information disclosure vulnerability
