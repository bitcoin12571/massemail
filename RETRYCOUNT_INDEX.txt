SYSTEM SUMMARY
==============

STATUS: FULLY IMPLEMENTED AND ACTIVE

COLUMN: retryCount (INTEGER, DEFAULT=0)
  Location: backend/src/models/Email.js (line 44)
  Database: mailora.sqlite (VERIFIED PRESENT)

RETRIES: Max 3 attempts with exponential backoff
  Attempt 1: Immediate fail -> wait 5 minutes
  Attempt 2: Still failing -> wait 15 minutes
  Attempt 3: Still failing -> wait 45 minutes
  Attempt 4+: Mark as 'failed', stop retrying

KEY SERVICE: emailRetryService.js
  markForRetry() - Schedule next retry
  getEmailsReadyForRetry() - Find emails to retry
  retryEmail() - Attempt resend
  processRetryQueue() - Orchestrate all retries

SCHEDULER: schedulerService.js
  Runs every 5 minutes
  Finds pending emails with nextRetryAt less than now
  Attempts resend for each

TESTING COMMANDS
================

Check current retry state:
  sqlite3 mailora.sqlite \
    "SELECT id, status, retryCount, nextRetryAt FROM Emails \
     WHERE retryCount > 0 ORDER BY nextRetryAt ASC LIMIT 10;"

  sqlite3 mailora.sqlite \
    "SELECT retryCount, COUNT(*) as count FROM Emails \
     GROUP BY retryCount;"

  sqlite3 mailora.sqlite \
    "SELECT id, retryCount, failureReason FROM Emails \
