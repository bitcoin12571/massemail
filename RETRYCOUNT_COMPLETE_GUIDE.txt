4. RETRY SERVICE IMPLEMENTATION

File: backend/src/services/emailRetryService.js

Function 1: markForRetry(emailId, reason)
Lines: 24-61
When Called: After email send fails
What It Does:
  1. Fetch email by ID
  2. retryCount = (email.retryCount || 0) + 1
  3. IF retryCount > 3:
       Status = 'failed', stop retrying
     ELSE:
       Calculate nextRetryAt with exponential backoff
       Save retryCount, lastRetryAt, nextRetryAt
       Email remains 'pending' for next retry

Function 2: getEmailsReadyForRetry()
Lines: 66-85
Query: WHERE status='pending' AND nextRetryAt <= now

Function 3: retryEmail(email, sendEmailFn)
Lines: 90-115
Flow:
  1. Call sendEmailFn(email) - from emailService.sendEmail()
  2. IF success: Update status='sent'
     ELSE: Call markForRetry() to schedule next attempt

Function 4: processRetryQueue(sendEmailFn)
Lines: 120-147
Orchestration:
  1. getEmailsReadyForRetry() - get pending emails
  2. For each email: Call retryEmail()
  3. Return metrics: { total, successful, failed }

Backoff Schedule:
  Retry 1: 5 minutes
  Retry 2: 15 minutes (3x delay)
  Retry 3: 45 minutes (9x delay)
  Fail: Mark as 'failed'

6. HOW RETRYCOUNT FLOWS

User Action
  Route Handler
    emailService.sendEmail()
      TRY/CATCH
        CATCH (email send fails)
          emailRetryService.markForRetry(emailId, error)
            email = Email.findByPk(emailId)
            retryCount = (email.retryCount || 0) + 1
            
            IF retryCount > 3:
              status = 'failed'
            ELSE:
              Calculate nextRetryDelay
              delay = 5min * (3 ^ retryCount)
              nextRetryAt = now + nextRetryDelay
              
              Email.update({
                retryCount,
                lastRetryAt: now,
                nextRetryAt,
                failureReason: error
              })

Background Scheduler (every 5 minutes)
  getEmailsReadyForRetry()
    SELECT * FROM Emails
    WHERE status='pending' AND nextRetryAt <= now
  
  For each email:
    retryEmail(email, sendEmailFn)
      Call sendEmail() again
      IF success: status = 'sent'
      ELSE: markForRetry() (recurse)
  
  Log results

10. DATABASE QUERIES

Check Pending Retries:
SELECT id, retryCount, nextRetryAt, failureReason
FROM Emails
WHERE status='pending' AND retryCount > 0
ORDER BY nextRetryAt ASC;

Check Failed Emails:
SELECT id, retryCount, failureReason
FROM Emails
WHERE status='failed' AND retryCount >= 3;

Retry Distribution:
SELECT retryCount, COUNT(*) as count
FROM Emails
WHERE status IN ('pending', 'sent', 'delivered')
GROUP BY retryCount;
