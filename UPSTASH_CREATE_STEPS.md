# 📝 UPSTASH - CREATE DATABASE STEPS

## STEP 1: Apasă "Create Database" (butonul verde)

## STEP 2: Completează formularul:
- **Database Name:** `email-dashboard-redis`
- **Region:** Alege cel mai apropiat:
  - `eu-west-1` (Ireland) - dacă ești în EU ✅
  - `eu-central-1` (Frankfurt) - alternativă
  - Sau altul dacă ești în alt continent
- **Database Type:** Redis (default)

## STEP 3: Apasă "Create"

## STEP 4: Așteaptă 2-3 secunde...

## STEP 5: După ce se creează, apasă pe database
- Vei vedea un panou cu detalii
- Caută sectiunea **"Redis CLI"** 
- Acolo vei vedea URL-ul de genul:
```
redis://default:PASSWORD@HOST:PORT
```

## STEP 6: COPIAZĂ URL-ul COMPLET
Exemplu (NU ESTE REAL):
```
redis://default:AHzX9k2jL3mN4pQ@us1-example.upstash.io:36379
```

## STEP 7: TRIMITE-MI URL-UL!
Vino înapoi și paste-aza URL-ul complet aici 👇
